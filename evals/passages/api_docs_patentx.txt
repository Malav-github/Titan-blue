PatentX API v1 documentation. The base URL for all requests is https://api.patentx.example/v1 . Every request must send your API key in the X-Api-Key header. The API is read-only: all endpoints use GET. GET /patents searches patent records. Query parameters: q (required, the search text) and limit (optional integer, default 10, maximum 100). GET /patents/{number} returns one patent record. The path parameter number is the publication number, for example WO2021037851A1. GET /families/{number} returns the patent family members of a publication number. The path parameter number is the publication number. Rate limits: 60 requests per minute. Responses are JSON. Errors use standard HTTP status codes; 401 means a missing or invalid key and 429 means you are over the rate limit.
