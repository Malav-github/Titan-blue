Records Open Data API. Base URL: https://data.records.example/api . Authentication: send an Authorization header with the value Bearer followed by your access token. Endpoint GET /records/search takes the query parameter term (required) and the optional integer parameter page. It returns matching records. Endpoint GET /records/{id} returns a single record; id is the record identifier. All endpoints are read only and return JSON. The service is free for up to 1,000 requests per day.
